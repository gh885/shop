## 全局共性（影响面最大，先修）

### G1. 搜索是死的 —— 缺「输入即建议」的浮层

- **在哪**：首页大搜索框、全部内页 `SearchHeader` 搜索框（`notifySearchComingSoon`）、`SiteNav`。
- **缺什么**：两个框都只弹 toast「搜索功能即将上线」。没有联想词浮层、没有历史、没有热词。
- **建议**：
    - 输入 ≥1 字即出 **下拉浮层**：联想商品（缩略图+标题+价格）+ 分类建议（可点击跳 feed）。
    - 空查询时出 **浮层默认态**：热搜榜 / 历史搜索（可清）。
    - 浮层项 hover 右侧显示「店铺名 / 销量」副信息，Esc / 点外关闭，点项直接进详情（新标签）。

### G2. 空购物车 / 无搜索结果 —— 缺「再逛逛」的行动型空态浮层

- **在哪**：购物车空态、收藏空态已有「去逛逛」，但**购物车 Settlement 缩略图超 4 件的 `+N`、feed 空态**只是文字。
- **缺什么**：`+N` 缩略图 hover 只显示「+N」，不告诉你另外 N 件是什么。
- **建议**：`+N` hover 弹 **缩略图网格浮层**（最多 12 个 + 「查看全部 N 件」），点任一格跳结算。这是结算前「我到底买了啥」的最后确认点。

### G3. 缺全局「Toast 之外」的阻塞式反馈位

- **在哪**：全站大量 `notify.info("…即将上线")`。
- **缺什么**：占位 toast 是唯一反馈，没有 loading 遮罩 / 错误对话框的统一模式给「真操作」。
- **建议**：保留 toast 做轻提示；**需要用户确认的动作**（下架、退款、批量删）已有 `confirm` —— 保持。**进行中**的按钮已有 `Spinner`。这块其实够用，标记为「无需动」。

## 买家端 web

### H1. 首页 · 商品流（Feed）

- **缺**：**商品卡的快速加购 / 快速查看浮层**。
    - 现在的卡只能点进详情（`target="_blank"`）。货架场景下用户想「先看规格、图快一点」或「直接加购」。
    - **建议**：卡 hover 出现右上角半透明两枚图标按钮：①「快速查看」→ 弹 **右侧抽屉/居中模态**，左边大图 + 规格丸 + 价格 + 加购（复用 PDP 的 PurchasePanel 数据），不进详情页；②「加购」直接入车 + 角标动画。
    - **缺**：**推荐条（RecommendBar）缺「这是什么」的浮层**。现在是一排词条、切 tab 换流，用户不知道词条是分类还是搜索型。加 **hover Tooltip** 说明该词条的圈定范围 / 类型。
    - **缺**：分类 mega 面板里词条点击**落回首页**（代码有 TODO），无分类页 —— 建议先把「词条 hover 出缩略预览 / 计数」铺好，等路由。

### H2. 首页 · 分类导航（HomeCategoryNav）

- **缺**：**行内词条截断后的完整名浮层**只有 `title` 原生 tooltip。
    - 建议：换 ui-web 的 Tooltip（已有 `Tooltip` 组件），显示完整名 + 一行「N 件在售」的计数。
- **缺**：**「商品分类即将上线」空态**没有 CTA。建议：空态里放「去看看全部商品」→ feed。
- **缺**：面板里**点词条跳分类/列表页的路由整体缺失**（TODO）—— 这是结构洞，不是浮层洞，但建议排期。

### H3. 首页 · 顶部 / 导航

- **缺**：站点头（`SiteHeader`）**无搜索框**（搜索在下面 HomeHeader / SiteNav）。可接受。
- **缺**：**面包屑 / 当前位置**在首页无所谓，但内页（详情/订单）应有 —— 见 P3。

### H4. 商品详情（PDP）

- **缺**：**规格选中的「不可售」组合没有前置提示浮层**。
    - 现在不可选值直接 `disabled` 变灰。灰掉但不说「为什么灰」（比如「这个色码已售罄」），用户盲猜。
    - **建议**：不可选丸 hover 弹 **Tooltip**：「已售罄 / 与已选色号冲突」，把「灰」翻译成人话。
- **缺**：**数量步进器旁的库存文字**是纯文本（`deriveStockText`），没有浮层解释「还剩 3 件，急」。建议：库存 <10 时数字旁挂一个**紧迫 Badge**（不是浮层，是小徽标）。
- **缺**：**服务承诺（发货/运费/7天退）纯文字一行**。建议：hover 任一条出 **Tooltip/Popover** 展开细则（退货运费谁出、发货含不含节假日）。或整块收成「服务说明 ⓘ」点击开 **Popover**。
- **缺**：**「本店推荐 / 看了又看」的商品卡无快速加购**（同 H1）。卡 hover 应有「快速查看 / 加购」，比只能跳详情强。
- **缺**：**分享 / 收藏浮层**。现在收藏只有一个心形按钮（`PurchaseCta`），无「分享给朋友」入口。建议：店条右侧或 CTA 区加「分享」→ Popover 复制链接 / 二维码。
- **缺**：**店铺条（ShopBar）的「进店 / 客服」是 toast 占位**。「进店」应至少弹一个 **店铺信息浮层**（店铺简介 + 在售分类 + 「进入店铺」），而不是空 toast。

### H5. 购物车

- **缺**：**行内「移入收藏」/工具栏的「分类 / 状态筛选 / 车内搜索」全是 toast 占位**。
    - **建议（车内搜索）**：把它做成真的 —— 工具栏搜索输入即过滤当前列表（前端过滤即可），或出 **下拉浮层**列出匹配条目。
    - **建议（分类 / 状态筛选）**：点开 **下拉浮层**（Checkbox 多选：分类、状态：有货/缺货/失效），浮层内多选即时过滤。
- **缺**：**行内无「商品详情浮层」**。hover 缩略图可弹 **大图预览浮层**（或放大镜），现在只能进详情。
- **缺**：**失效条目（缺货/下架）缺原因浮层**。`deriveCartItemView` 置灰 + 「缺货」Badge，但「已下架」「已售罄」等具体原因没有入口。建议 hover 置灰行 → **Tooltip** 给原因 + 「去相似商品」链接。
- **缺**：**Settlement 缩略图 `+N` 无浮层**（同 G2）。
- **缺**：**优惠/满减/红包在 Settlement 留白**（代码注释「本期不做」）。等真实优惠接入时，右栏应有「优惠明细 Popover」，hover 金额展开「券 / 活动」明细。

### H6. 结算页（Checkout）

- **缺**：**地址区无「管理地址」入口浮层**。只列地址卡 + 无「新增」。建议卡区右上角「+ 新增地址」→ 弹 **AddressFormDialog**；或「管理」→ 地址列表浮层。
- **缺**：**默认地址当前高亮，但没有「设为默认」快捷**。建议每个地址卡 hover 出现「设为默认」小按钮。
- **缺**：**已失效商品（UnavailableCard）**只是一段文字列表，**不可点**。建议每行 hover 出 **Tooltip / 换商品入口**（去详情挑同款）。
- **缺**：**运费金额无解释浮层**。右栏「运费 ¥X」是死数。建议 hover 运费 → **Popover** 展示该店运费模板（首重/续重/包邮门槛），让买家懂为什么是这个数。
- **缺**：**应付总额无「已省多少」呼应**。有优惠时建议总额下方加「已优惠 ¥Y」+ 绿色，hover 优惠行展开明细。
- **缺**：**提交订单按钮无二次确认/无结果浮层**。金额较大时按「提交」直接下单。建议金额超阈值时 **confirm 确认单**（含地址 + 金额）。这是保护性交互。

### H7. 收银台（Pay）

- **缺**：**支付方式选择浮层/卡片缺失**。现在只有「模拟支付通道（MOCK）」一句话 + 一个「确认支付」按钮。
    - **建议**：即使 V1 是 mock，也应渲染一张 **支付方式卡**（微信/支付宝，选中态），hover/点击切换。让「收银台」有事可做，也为将来真实通道留位。
- **缺**：**订单号不可复制**。`订单号 {order.orderNo}` 是纯文本。建议用 `CopyableText`（仓库已有），hover 出复制。
- **缺**：**「取消，返回订单」语义弱**。建议改成「稍后支付」并补一句「订单保留 X 分钟」说明（配合倒计时）。

### H8. 订单详情 / 订单列表

- **缺**：**订单卡的「订单号」不可复制**。`OrderCard` 里订单号是 span，建议换 `CopyableText`。
- **缺**：**无「再次购买 / 再来一单」浮层入口**。订单已完成/已取消时，底部建议出现「再次购买」→ 弹 **SKU 失效检查浮层**（哪些还能买、哪些变了），确认后进购物车。这是复购主路径。
- **缺**：**订单详情页缺「联系卖家 / 申请售后」的统一入口浮层**。现在操作按钮散在卡片上。建议详情页右侧/底部给一个「订单操作」区，hover 出现「联系客服」。
- **缺**：**物流单号在订单详情里应可复制 + 可跳物流页**。物流页 `CarrierBar` 有单号，订单详情应有对应入口。

### H9. 物流详情

- **缺**：**承运商单号无「复制单号」浮层**。`CarrierBar` 展示 trackingNo，建议加 copy。
- **缺**：**收货信息（ReceiverLine）无「复制地址」**。建议整行可点复制完整地址 + 电话。
- **缺**：**一单多包裹缺「切换包裹」的浮层导航**。现在多条包裹顺铺，商品多时很长。建议顶部一个 **包裹 Tab 浮层/胶囊**（包裹 1 / 包裹 2），点击滚到对应轴。

### H10. 账户 · 我的券包（Coupons）

- **缺**：**券卡无「用券去哪」浮层 / 无去使用入口**。「未使用」页签的券应可点 → 跳「去使用」→ 走 feed 选品或结算。建议券卡 hover 出「去使用」按钮。
- **缺**：**券卡无规则详情浮层**。「满 200 减 30」hover 展开「适用范围 / 有效期 / 可叠加否」。现在只有 title 一行。

### H11. 账户 · 优惠券 / 收藏 / 地址

- **收藏**：搜索框有，但**无「空结果」引导浮层**。可加「没找到？清空搜索」。
- **地址**：地址列表/编辑已有 Dialog。**缺默认地址标识的说明浮层**？小项，可不做。

## 卖家端 seller

### S1. 全局顶栏（AppTopBar）

- **缺**：**四个动作图标（消息/规则/帮助/客服）全是死按钮，无任何浮层**。这是最典型的「一排图标点了没反应」。
    - **建议**：
        - **消息（Bell）**→ 点击开 **Popover/抽屉**：通知列表（新订单 / 售后申请 / 超时未发货），未读红点。`dot` 属性已预留，缺内容。
        - **规则（BookOpen）**→ **Popover** 内嵌平台规则速查（发货时限、券规则、售后规则）。
        - **帮助（?）**→ **抽屉** 常见问题。
        - **客服（Headset）**→ 至少弹 **联系客服浮层**（二维码/会话入口），别空。
- **缺**：**账号区（AccountChip）无店铺切换浮层**。多店铺场景下，头像 hover 菜单应能切店。

### S2. 订单列表（OrderTable）

- **缺**：**行内「商品」单元只有缩略图 + 标题 + 共N件，无订单详情浮层**。卖家高频需求是「点一行看这单明细」。
    - **建议**：整行 hover 高亮 + 左侧商品缩略图 hover 弹 **订单快照浮层**（全部行项 + 收货信息 + 金额），不跳页。
- **缺**：**订单号已有 CopyableText（好）**；但**手机号明文「查看」后无「已查看」浮层留痕**。现在看一次明文按钮就没了（`MaskedValueCell`），建议看过的行标一个「已查看」小标（合规留痕）。
- **缺**：**状态页签（OrderFilterBar）无「各状态数量」角标**。建议每个 Tab 上挂 **Badge 计数**（待发货 3 / 售后 1），卖家一眼知道该去哪个。这是后台类产品的核心信息密度，缺了很伤。
- **缺**：**无「批量发货 / 批量处理」浮层**。多选后应有批量操作（发货/同意售后/标记）。现在无多选。
- **缺**：**售后徽章（AFTER_SALE_META）hover 无详情浮层**。建议 hover 出售后单摘要（原因/金额/发起时间），点进决策。
- **缺**：**「超时未发货」Badge 无说明**。hover 说明「承诺 X 前发货，已超时，建议尽快处理」。

### S3. 订单 / 退款 列表

- **缺**：**RefundTabs / OrderFilterBar 页签同样无计数角标**（同 S2）。
- **缺**：**退款列表行缺「买家申请理由」的详情浮层**。同意/拒绝前，卖家应能 hover 看买家原话 + 图片凭证。建议行 hover 或决策弹窗里展示。

### S4. 发货弹窗（ShipDialog）

- **缺**：**发货信息（快递公司/单号）无「智能识别 / 历史单号复用」浮层**。建议单号输入框提供 **Combobox 浮层**（该店历史承运商 + 常用单号）。
- **缺**：**发货成功后无「打印面单 / 复制发货信息」浮层**。发完货给一个「发货成功」模态，内含「复制发货信息」「查看物流」。

### S5. 商品列表（ProductTable）

- **缺**：**商品列表无「预览商品」浮层**。编辑走跳页，但卖家想「不离开列表看效果」。建议缩略图 hover 弹 **商品预览浮层**（主图 + 标题 + 价格 + 状态），点「编辑」才跳。
- **缺**：**价格/库存编辑弹窗（EditSkuDialog / EditStock）之外，列表单元格 hover 已有编辑图标（好）**。但**库存 0 / 库存低无「预警 Badge」**。建议库存 <阈值 时单元格挂 **warning Badge** + hover 说明。
- **缺**：**商品状态（下架/上架）无「操作确认后结果浮层」**。下架有 confirm（好），上架没有。建议上架也可选填「理由」并给结果 toast。
- **缺**：**批量操作缺失**。多选后批量上下架 / 批量改类目。列表页无复选框列。

### S6. 商品发布（create/basic + SkuGridEditor）

- **缺**：**SKU 表格无「SKU 预览 / 买家视角」浮层**。卖家填完 SKU 不知道买家看到啥。建议表格上方一个「买家视角预览」按钮 → 弹 **PDP 预览浮层**（复用 PurchasePanel）。
- **缺**：**批量设置价格/库存的浮层**。SkuGridEditor 若有「批量」按钮，应弹一个 **批量设置 Popover**（统一价格 / 统一库存）。若已有，检查是否有。
- **缺**：**图片区（DetailImagesSection）缺「拖拽排序 / 主图设置」的提示浮层**。建议 hover 图片出排序把手 + 「设为主图」角标。

### S7. 优惠券管理（`routes/_app/marketing/coupon.tsx` / CouponTable）

- **缺**：**券列表无「使用情况」浮层**。每张券应显示 / hover 可看「已领 N / 已用 M / 带来 GMV」。建议列上挂 **数据浮层**（领取率、核销率）。
- **缺**：**券的「适用范围 / 生效状态」hover 无说明**。「未开始/进行中/已结束」应 hover 出时间范围 + 状态解释。

### S8. 运费模板（ShippingTemplatePage + FeeTierInputs + RegionMultiPicker）

- **缺**：**运费模板无「买家视角算运费」预览浮层**。建议模板编辑页右侧一个「模拟买家下单」卡：输入目的地 + 数量 → 实时算运费。这是运费模板最容易出错的地方。
- **缺**：**RegionMultiPicker（多地区选）应有「已选 N 个地区」浮层汇总**。选了几十个地区时，应能 popover 展开查看/清除。

### S9. 店铺 · 会员 / 地址

- **会员**：**会员列表无「会员详情」浮层**。建议行 hover 弹该会员画像（消费额/单数/最近下单）。检查是否已有详情页。
- **地址**：发货地址管理，**应有「默认地址」标识浮层说明**，小项。

## 管理端 admin

### A1. 侧边导航 + 顶栏（AppSidebar / app-topbar）

- **缺**：**顶栏通知/帮助类动作是否全死需确认**（对齐 S1）。若死，同样处理。
- **缺**：**无「面包屑」**。管理端深层页面（分类 / CMS）应有当前位置浮层导航，便于定位。

### A2. 店铺审核（店铺审核队列首页）

- **缺**：**审核行无「店铺详情」浮层**。审核要决策「通过/驳回」，管理员需要看全貌：店铺名/类目/提交材料/店主电话。建议整行 hover 弹 **审核详情抽屉**（材料预览 + 电话 + 通过/驳回按钮），不跳页。
- **缺**：**状态筛选下拉（Select）无计数角标**。建议每个状态挂 Badge 数量（待审 5 / 已通过 20），管理端核心信息密度。
- **缺**：**「通过/驳回」无「驳回理由」必填浮层**。驳回应弹 **Popover 收理由**（不通过的原因），让卖家知道怎么改。这是合规/体验关键。
- **缺**：**店主电话明文「查看」后无留痕**（同 S2），且无「查看原因」说明。建议看过的行留「已查看」标 + Tooltip 说明「查看会留痕」。

### A3. 类目管理（categories + attr-panel + category-tree）

- **缺**：**类目树 hover 无「快捷操作」浮层**。建议节点 hover 出「+子类目 / 编辑 / 删除」小图标组。
- **缺**：**属性面板（AttrPanel）缺「属性值示例 / 录入引导」浮层**。建议输入框 hover 出「示例：颜色 / 尺码」。

### A4. CMS（banner / nav / recommend-tab）

- **缺**：**Banner 列表无「预览效果」浮层**。运营改 Banner 想知道买家端长什么样。建议缩略图 hover 弹 **首页位置预览**（手机框模拟）。
- **缺**：**推荐 Tab 列表无「这个词条当前带多少商品 / 效果」浮层**。建议 hover 看「覆盖 N 商品 / 近期点击」。
- **缺**：**导航（nav）无「前台效果预览」浮层**。建议编辑时右侧/hover 出「首页导航栏预览」。

### A5. 优惠券运营（coupon-ops）

- **缺**：**券列表无「发放/使用数据」浮层**。同 S7，建议每列数据 hover 展开明细。
- **缺**：**作废动作（void-action）无「作废后影响」说明浮层**。作废不可逆，应在 confirm 里说明「已领用户将无法使用 / N 人受影响」。

### A6. 账号管理（users / staff）

- **缺**：**用户/员工列表无「详情」浮层**。建议行 hover 弹画像（注册时间/订单数/状态历史）。
- **缺**：**「禁用/启用」无「影响范围」浮层**。禁用员工应说明「将立即收回其登录权限」。

## 附：共性设计原则（写给实现时的约束）

1. **列表页 = 行 hover 出「详情浮层」**。凡是表格/货架，密集信息行都该能 hover 看全貌，不跳页。这是后台与货架的通用范式。
2. **状态页签必带计数角标**。Tab 不带数量，用户就得逐个点，密度白瞎。
3. **置灰/禁用必带原因**。任何 disabled 元素，hover 要能解释「为什么灰」。
4. **死按钮不留**。占位 toast 只在开发期出现；正式形态要么给浮层，要么不渲染图标。
5. **金额/单号/地址可复制**。`CopyableText` 已就绪，该铺的地方铺上去。
6. **决策类操作走「抽屉看全貌 + 浮层收条件」**。审核、退款、驳回都是不可逆决定，需要在同一浮层内看完再点确认。
